# Reproduction

1. Rebuild the conda base from config/conda_explicit_lock.txt on macOS arm64. These are exact package build URLs and hashes. The base provides Python, PLIP and Open Babel.
2. Create a venv with --system-site-packages from that base Python. Install config/complete_environment_lock.txt into it, preserving the already installed conda Open Babel. Verify imports/versions against software_versions.json. Do not update this environment during a run.
3. Supply AutoDock Vina 1.2.7 arm64 with the SHA256 recorded in software_versions.json. The original binary's installer source is not known; a version string alone does not guarantee identical binary bytes.
4. Code lives in src/standardized_redocking.py, standardized_plip.py, standardized_structure_analysis.py and standardized_external.py. Path constants identify this workspace's environment. For another workspace explicitly set the matching environment/path constants, retain version/hash verification, and create a new run. Do not point output into a historical run.
5. Run stages in order: `python -m src.standardized_redocking init`, `prepare`, `dock`; `python -m src.standardized_plip all`; `python -m src.standardized_structure_analysis`; only after STRUCTURAL_RESULTS_FROZEN.json is present and verified run `python -m src.standardized_external`.
6. All seeds/boxes/preparation/analysis conditions are in the frozen run config. Preserve CPU=1 per Vina job, OMP_NUM_THREADS=1, OPENBLAS_NUM_THREADS=1. Four independent jobs can run concurrently. Resume only completed job manifests; do not rerun because of docking score.
7. raw/archives contains lossless per-drug tar.gz archives of docking logs, all returned pose PDBQT, per-pose ligand SDF and raw PLIP XML/TXT/status. Each full PLIP complex is deterministically reconstructed by `complex_pdb` from the retained block-specific prepared_H.pdb and poses.pdbqt via pinned Meeko RDKitMolCreate (SDF is an additional rounded export); the original input SHA256 is in pose_manifest.csv. Scratch full protein copies are not required in the archive.
8. Legacy TORSDOF0 made every input ligand rigid in the old PDBQT torsion tree. This run uses Meeko branches and audited torsions; its frequencies are a new dataset and are not required to match historical frequencies.

Preparation flags: no pH-dependent state enumeration; no ring-conformer ensemble; source-unspecified stereocentres remain flagged and are represented by one sampled configuration, not all enantiomers. Open Babel reported aromatic kekulization warnings on full receptor reading; binding-site aromatic atom types and six specified residue mappings are separately audited. Preserve these warnings and do not interpret the whole receptor preparation as experimentally validated.

Implementation references: https://meeko.readthedocs.io/en/develop/lig_prep_basic.html and https://github.com/pharmai/plip/blob/master/DOCUMENTATION.md (local installed package code/config is authoritative for actual settings).
